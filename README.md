# 📷 Rust 超高速画像ビューア (Rust Image Viewer)

Rust + `egui` で構築された、起動 0.1 秒・軽量・超高速な Windows 用デスクトップ画像ビューアアプリケーションです。

---

## 📥 インストール不要！`.exe` の直接ダウンロード

コンパイルや環境構築は不要です！以下のリンクから直接バイナリをダウンロードしてすぐに利用いただけます：

👉 **[最新版 `.exe` をダウンロード (Releases ページへ)](https://github.com/NoGinger333/rust-image-viewer/releases)**

ダウンロードした `rust-image-viewer.exe` をダブルクリック、または画像ファイルをそのままドラッグ＆ドロップ（または「このプログラムで開く」に設定）するだけで即座に起動します。

---

## ✨ 主な特徴と機能

- ⚡ **超高速・軽量動作**: 起動 0.1 秒以下！バックグラウンド非同期先読み ＆ キャッシュ制御でフォルダ内の画像をサクサク閲覧
- 📂 **サイドバー画像一覧**: フォルダ内の画像一覧を表示。設定（ON/OFF）は次回起動時にも自動保存・復元
- 🔍 **スムーズなズーム ＆ パン**: `Ctrl + マウスホイール` またはボタン操作で自由拡大・縮小
- 🖱️ **直感的なスクロールページ送り**: 1 スクロール操作で 1 枚確実切り替え。高速回転時も途中で引っかからない滑らかなロック解放
- 🎨 **洗練されたモダンUI**: 
  - フラットで美しい単色ベクトル風ツールバーアイコン
  - 画面左右の端にカーソルを近づけた時だけ「ふわぁ」とフェード表示されるナビゲーションボタン
  - ダークモード ↔ ライトモード切替対応
  - 鮮やかなオレンジ背景 ＋ 白色のオリジナルアプリアイコン搭載
- 🔕 **コンソール画面非表示**: 起動時に不要な黒い cmd 画面が開かず、GUI 画面だけがサクサク高速起動

---

## ⌨️ ショートカットキー一覧

| 操作 | キー / マウス |
|---|---|
| 画像切り替え (前/次) | `←` / `→` キー、または マウスホイール |
| 拡大・縮小 (ズーム) | `Ctrl` + マウスホイール、または ツールバーの ➕ / ➖ |
| 表示位置リセット | `R` キー、または ツールバーの ↺ |
| ウィンドウフィット | `F` キー、または ツールバーの ⛶ |
| ファイルを開く | `Ctrl` + `O` |

## 🛠️ ソースコードからのビルド (開発者向け)

```bash
# リポジトリのクローン
git clone https://github.com/NoGinger333/rust-image-viewer.git
cd rust-image-viewer

# リリースビルドの実行
cargo build --release
```

生成されたバイナリは `target/release/rust-image-viewer.exe` に配置されます。

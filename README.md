# 🖼️ Rust 高性能画像ビューア (Rust Image Viewer)

Rust と GPU アクセラレーションに対応した GUI フレームワーク [`eframe` / `egui`](https://github.com/emilk/egui) で構築された、高速・軽量・多機能なデスクトップ画像ビューアアプリケーションです。

---

## ✨ 主な機能

- **📁 多様な画像フォーマット対応**: PNG, JPEG, WEBP, GIF, BMP, TIFF などの読み込み・表示。
- **🖱️ インタラクティブ操作**:
  - マウスホイールによるスムーズな拡大・縮小（ズームイン / ズームアウト）
  - マウスドラッグによる自由な移動（パン）
  - ダブルクリックやボタン操作での「ウィンドウフィット」 / 「原寸(100%)表示」
- **🔄 回転・反転機能**: 90度単位の回転（時計回り）、左右反転、上下反転。
- **📂 フォルダ自動スキャン & サイドバーナビゲーション**:
  - 開いた画像と同じフォルダ内の他の画像を自動認識。
  - 画面左右のオーバーレイボタン、キーボード矢印キー（`←` `→`）、またはサイドバーからのワンクリック切替。
- **📥 ドラッグ＆ドロップ**: アプリウィンドウに画像ファイルをドラッグ＆ドロップして即座に表示。
- **📊 メタデータ表示**: ファイル名、解像度（幅 × 高さ）、ファイルサイズ、現在の拡大率を表示。
- **🌓 テーマ切り替え**: ワンクリックでのダークモード / ライトモード切替。

---

## ⌨️ キーボードショートカット

| キー | 操作内容 |
| :--- | :--- |
| `Ctrl + O` | ファイル選択ダイアログを開く |
| `←` / `→` | 前の画像 / 次の画像へ切り替え |
| `R` | ズーム・位置・回転状態をリセット |
| `F` | ウィンドウフィットモードに切替 |
| `ホイールスクロール` | 拡大 / 縮小 |
| `ドラッグ` | 画像を自由にパン（平行移動） |

## 🚀 ビルド & 実行方法

### 必要な動作環境
- **Rust ツールチェーン** (`rustup`, `cargo`, `rustc`)

> Rust が未インストールの場合は、[https://rustup.rs/](https://rustup.rs/) からインストールしてください。

### 実行手順

1. ターミナルで本ディレクトリを開きます。
```bash
cd path/to/optimistic-lovelace
```

2. 開発モードで実行する:
```bash
cargo run
```

3. 最適化ビルド（リリースモード）で実行する:
```bash
cargo run --release
```
